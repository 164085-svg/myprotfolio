## 👋 About Me

สวัสดีค่ะ ดิฉันชื่อ **นางสาวอธิปจิรา มณีโชติ**
ชื่อเล่น **ตังตัง**

ดิฉันเป็นผู้ที่มีความสนใจในด้าน **ภาษาและการสื่อสาร**
เพราะมองว่าการสื่อสารไม่ได้เป็นเพียงการพูดให้ผู้อื่นเข้าใจ
แต่ยังเป็นการเรียนรู้ความคิด วัฒนธรรม
และมุมมองที่แตกต่างของผู้คน

## 🌏 My Passion

หนึ่งในประสบการณ์ที่ทำให้ดิฉันสนใจด้านภาษาอย่างจริงจัง
คือการได้มีโอกาส **สื่อสารกับชาวต่างชาติ**

ประสบการณ์นี้ทำให้เห็นว่าการใช้ภาษาในชีวิตจริง
มีความแตกต่างจากการเรียนในห้องเรียน
และทำให้ดิฉันกล้าที่จะฝึกฝน เรียนรู้
และยอมรับความผิดพลาดของตนเองมากขึ้น

นอกจากนี้ การเรียนรู้ภาษาและวัฒนธรรมของประเทศอื่น
ยังช่วยให้ดิฉันเปิดกว้างต่อความแตกต่าง
และเข้าใจผู้คนมากยิ่งขึ้น
